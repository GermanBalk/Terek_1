          # Random Task Generator
**Автор:** Герман Балкаров
## Описание
Программа позволяет генерировать случайные задачи из предопределенного списка, добавлять свои задачи, фильтровать их по типам и сохранять историю выполненных задач. Все данные сохраняются в файле `tasks.json` и автоматически загружаются при запуске.

## Использование
- Нажмите "Сгенерировать задачу" — получите случайную задачу.
- Используйте радиокнопки для фильтрации по типу (учёба, спорт, работа, все).
- Нажмите "Добавить свою задачу" — введите описание и тип задачи.
- В списке отображаются все задачи с их типами.
- Историю задач сохраняется между запусками.

## Тестовые сценарии
- Генерация случайных задач
- Добавление новых задач
- Фильтрация по типу
- Проверка сохранения и загрузки данных
